# Seedshop: источники исследования UI/UX

Дата обращения ко всем внешним источникам: **17 октября 2026**. Это реестр проверенной выборки, а не рейтинг магазинов и не перечень всех исследований в мире. Основной документ: [UI-UX-RESEARCH.md](UI-UX-RESEARCH.md).

## Как читать реестр

- **R** — исследование или обобщение наблюдений. Перенос на нашу аудиторию требует проверки.
- **N** — нормативный технический документ. Критерий соответствия не гарантирует удобство всего продукта.
- **G** — практическое руководство, документация или стандарт сообщества.
- **M** — рыночная статистика с собственной методикой и периодом.
- **O** — наблюдаемое содержание действующего сайта. Не доказательство конверсии или качества реализации.
- **A** — отдельное пользовательское сообщение; сигнал для гипотезы, не распространённость проблемы.
- **Открыт** — получен текст страницы и просмотрены относящиеся к исследованию фрагменты. Это не означает полное чтение всех вложенных отчётов или проверку интерфейса в браузере.
- **Ограничен** — доступен поисковый фрагмент либо другой контент вместо ожидаемого. Такой источник не используется как самостоятельное основание обязательного изменения.

## Журнал поиска и отбора

Поиск проведён по следующим группам запросов на русском и английском; после поиска открывались первоисточники и уточнялись нужные фрагменты:

1. E-commerce product lists / filters / search query types / autocomplete / product page images / checkout / guest checkout.
2. Visual hierarchy / aesthetic-usability / older adults / usability heuristics / thinking aloud.
3. WCAG 2.2 / target size / focus not obscured / form validation / error summary / motion.
4. Web Vitals / product structured data / ecommerce URL structure / design tokens / inventory bulk editing.
5. Российская интернет-торговля 2025–2026 / Data Insight / АКИТ; US Census и Eurostat для международного контекста.
6. Johnny’s / Burpee / Thompson & Morgan / Baker Creek / Gardener’s Supply; Гавриш / Semena.ru / Seedspost.
7. Gardening community: maturity dates, quantity in packets; merchant community: inventory and bulk updates.
8. Trustworthy experimentation / deceptive patterns / B2B cart collaboration.

Не включены как доказательная база: SEO-пересказы без методики, рекламные обещания роста конверсии, копии статей через посторонние proxy-домены, тексты с неясным происхождением, единичные объявления разработчиков о собственном продукте. Отдельные платные Baymard-страницы найдены, но их закрытая часть не читалась. X, HN, закрытые сообщества и внутренние клиентские записи не исследовались: они не нужны для подтверждения выбранных базовых рекомендаций и их охват не заявляется.

## Как продолжать реестр

Для нового источника сохранять ID, дату обращения, точную страницу, тип доказательства, одно конкретное наблюдение, ограничение и связанные UX-ID из [списка возможностей](UI-UX-OPPORTUNITIES.md). При смене содержимого страницы не переписывать старое наблюдение как будто оно сделано сегодня: отметить новую проверку и дату. Не складывать сюда полные чужие статьи, платные отчёты или чужие товарные фотографии.
